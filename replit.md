# GyanteyAcademy Client

An Angular 22 frontend application.

## Running the app

```bash
npm start
# or
ng serve
```

The dev server runs on port 5000 and is configured to allow all hosts (required for Replit's preview proxy).

## Stack

- Angular 22
- TypeScript 6
- RxJS 7
- Vitest (unit tests)
